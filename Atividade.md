1º Mostrar o Projeto Funcionando para todos os dev

2º o Projeto possui 20 erros que precisam ser corrigidos, mas precisa commitar de forma semântica cada erro

3º Criar um Fork do Projeto em um repositório de sua Organização(caso não tenha crie uma)

4º com o projeto aberto no vscode, crie uma branch dev e outra teste

5º na branch dev comece a debugar o projeto, cada erro encontrado faça o commit semântico correspondente

6º antes de enviar para main, faça um teste na branch teste e verifique se tudo está ok

7º Agora sim pode ir para main fazer o merge e dar o push para o repositório

8º Volte para  a branch dev e coloque no readme.md os 20 erros encontrados

9º volte para a main e suba essa alteração com o commit correspondente

10º depois de tudo certo é hora de entregar ao cliente o projeto, hospede-o no GitPages, e passe o link para o cliente acessar.
